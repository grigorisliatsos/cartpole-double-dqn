# CartPole-v1 with Double DQN

Deep Reinforcement Learning project for solving the CartPole-v1 environment using PyTorch and Gymnasium.

## Features

- Double Deep Q-Network (DDQN)
- Experience Replay
- Target Network
- Epsilon-Greedy Exploration
- Huber Loss
- Gradient Clipping
- Hyperparameter Experiments

## Project Structure

main.py
Training and hyperparameter experiments

play.py
Visual demonstration of the trained agent

results_cartpole_dqn/
Saved models and training results
